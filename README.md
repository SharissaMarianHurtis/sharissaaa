## About Me

I’m a Software Engineer and MCA graduate interested in building practical software systems and understanding how applications work across the stack.

My experience spans **backend development, REST APIs, databases, application support, debugging, testing, and technical problem-solving**. I enjoy working through a problem from its requirements and business logic to implementation, data handling, API integration, testing, and troubleshooting.

My current technical focus is **Java, Python, SQL, backend engineering, APIs, software engineering, and modern development tools**.

Beyond development, I explore **AI and emerging technologies** through projects, academic work, technical research, and technology writing.

I also served as **Team Lead of TECHTITTANS** at Smart India Hackathon 2023, representing Rajagiri College of Social Sciences, where the team was selected for the **Grand Finale in the Software category**.
